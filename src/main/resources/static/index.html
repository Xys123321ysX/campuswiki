ABOUT THE PROJECT

Built for Curious Students

Campus Wiki is a demonstration web application developed using Java and the Spring Boot framework.

The project introduces the fundamental concepts of web application development, including server-side execution, HTML structure, CSS styling and responsive interface design.

Its goal is to provide an accessible, organized and welcoming starting point for exploring campus-related information.

PROJECT TECHNOLOGIES

Modern Web Development

Backend: Java 21

Framework: Spring Boot 4.0.9

Frontend: HTML5 & CSS3

Build Tool: Apache Maven

IDE: Visual Studio Code
